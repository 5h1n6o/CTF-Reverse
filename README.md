# CTF - Reverse

CTF の Reverse（リバースエンジニアリング）ジャンルを体系化したリポジトリです。  
静的解析・動的解析・難読化解除などを扱います。

---

## 📘 章構成

### 静的解析
- Ghidra  
- IDA  
- バイナリ構造  
- 関数解析  

### 動的解析
- gdb  
- breakpoints  
- メモリ解析  

### 難読化解除
- Control Flow Flattening  
- Junk Code  
- Encryption / Decryption  

### 文字列復号
- XOR  
- Base 系  
- カスタム暗号
